# 양방향 번역 — SillyTavern 확장

[LV-Translator](https://github.com/mallang0723/LV-Translator)(Lumiverse 확장)의 SillyTavern 이식판입니다. 응답과 내 메시지를 AI로 번역합니다. Marinara Engine의 번역 기능을 참고해 만들었고, 아래 세 가지를 합쳤습니다.

- Marinara Engine의 기본 AI 번역: 응답 자동 번역, 내 메시지 번역, 번역문만 보기, 입력창 번역 버튼
- [번역 프리셋·단어장 1.5.4](https://github.com/minikkeuen/Marinara-Translation-Tools/releases/tag/1.5.4): 프리셋 전체, 채팅별 단어장, 기타 지침, 대사 지침, 이전 대화 참고
- **끊긴 번역 이어서 하기**와 긴 지문 나눠 번역 (번역 다듬기 0.2.3에서 착안, 코드는 새로 작성)

여기에 번역하지 않을 부분(상태창 등) 지정, HTML 구조 보존, 번역문의 HTML 렌더링을 더했습니다.

SillyTavern에도 내장 "Chat Translation"이 있지만, 이 확장은 자체 번역 엔진으로 번역합니다. 내장 기능은 아래 설치 안내대로 끄세요.

## 설치

1. SillyTavern → 확장(Extensions) → **확장 설치(Install extension)**를 엽니다. 주소 칸에 `https://github.com/mallang0723/ST-Translator`를 넣고 설치를 누릅니다. 브랜치 칸은 비워 두면 됩니다(기본 브랜치 main이 설치됩니다).
2. 확장 패널의 **양방향 번역** 서랍, 또는 마술봉(확장 메뉴)의 **번역 설정** 항목에서 설정합니다.
3. **SillyTavern 내장 "Chat Translation"의 자동 번역 모드를 끄세요.** 켜 둔 채로 쓰면 같은 메시지가 두 번 번역됩니다.

## 사용법

연결 선택은 바로 저장되고, 나머지 설정은 **저장** 버튼을 눌러야 적용됩니다. 저장하지 않은 변경이 있으면 저장 줄이 강조되고 "저장하지 않은 변경이 있어요"가 표시되며, 번역·이어서 번역·입력창 번역 버튼을 누르거나 페이지를 떠날 때 한 번 더 물어봅니다(번역 버튼에서는 **저장하고 번역**을 고를 수 있습니다).

설정은 **채팅마다** 저장됩니다. 단 **AI 연결은 모든 채팅에 공통**인 하나의 설정입니다. 채팅이 열려 있지 않을 때 저장하거나 **저장 + 새 채팅 기본값으로**를 누르면, 아직 설정이 없는 채팅의 기본값이 됩니다. 프리셋은 모든 채팅이 함께 씁니다.

모든 번역은 브라우저에서 실행됩니다. 번역이 도는 중에 브라우저 탭을 닫으면 번역도 멈춥니다.

### 기본 번역 (Marinara 채팅 번역 설정과 같음)

| 설정 | 설명 |
|---|---|
| 번역에 쓸 AI 연결 | SillyTavern **연결 프로필(Connection Manager)** 중 하나. **고르는 즉시 저장됩니다.** 모든 채팅에 공통입니다. 순서는 **고른 연결 → 지금 쓰는 연결 프로필 → 지금 쓰는 API**입니다. 고르지 않았고(자동) 지금 선택된 연결 프로필도 없으면 **지금 쓰는 API 연결**로 번역합니다. 고른 프로필이 삭제되면 지금 쓰는(없으면 기본·첫) 연결 프로필로 대신 번역하고 알려 줍니다 |
| 번역 최대 출력 토큰 | 번역 한 번의 최대 출력 길이(기본 4096, 256~65536). 긴 메시지가 잘린다면 올리세요 |
| 모델 언어 / 내 언어 | 내 메시지는 모델 언어로, 응답은 내 언어로 번역 |
| AI 응답 자동 번역 | 응답 생성이 끝나면 저장된 최종 응답을 번역 |
| 번역이 끊기면 자동으로 이어서 번역 | 모델이 출력 한도로 멈추면 그 자리부터 이어서 번역(최대 4회). 지금 쓰는 API로 번역할 때는 끊김을 알 수 없어 동작하지 않습니다 |
| 번역문 표시 방식 | 원문 아래에 번역문 / **번역문 먼저(번역문 아래에 원문)** / 번역문만 / 원문 + 접힌 번역문 / **번역문 + 접힌 원문** / **문단 대조** (아래 참고) |
| 번역 단위 | 메시지 통째로(1회 요청) / 문단별(문단마다 1회 요청) |
| 내 메시지를 보내기 전에 번역 | 보내기 직전에 번역해, 번역문을 메시지 내용으로 저장하고 AI에게도 번역문을 보냅니다. 실패하면 원문을 보내고 알림 |
| 입력창 옆에 번역 버튼 표시 | 보내기 버튼 옆의 번역 아이콘. 입력 중인 글을 모델 언어로 번역해 입력창에 넣음. 그대로 보내도 다시 번역하지 않음 |

**번역문 + 접힌 원문**은 번역문을 먼저 보여 주고, 아래의 **원문**을 누르면 원문 전체를 펼칩니다. 번역문이 아직 없거나 번역에 실패해 표시할 번역문이 없으면 원문을 그대로 보여 줍니다. 기존 채팅과 기본 설정의 표시 방식은 바뀌지 않습니다.

### 메시지별 버튼

각 메시지의 **동작 줄**(수정·복사·숨김·분기·삭제 아이콘이 있는 줄) 끝, 연필(수정) 아이콘 앞에 아이콘 두 개가 붙습니다.

- **번역(지구본 아이콘):** 번역합니다. 이미 번역이 있으면 "다시 번역"으로 새로 번역합니다. 번역 중에는 깜박이며 누르면 중단합니다.
- **번역 삭제(지우개 아이콘):** 지금 보이는 스와이프의 번역문만 지웁니다(확인을 한 번 묻습니다). 그 스와이프에 번역이 있을 때만 보이고, 다른 스와이프의 번역과 메시지는 그대로입니다. 스와이프를 넘기면 버튼이 따라 바뀝니다. 호스트의 휴지통(메시지 삭제)과 다른 아이콘입니다.

메시지 아래 작은 줄은 번역 중 진행·취소, 오류, "번역이 중간에 끊겼습니다 (2/5)"와 **이어서 번역**, **번역 보기/숨기기**가 있을 때만 나타납니다. 번역 숨기기는 스와이프가 아니라 메시지 전체에 적용됩니다. 문단 대조에서는 번역 보기/숨기기가 없고, 번역 중·오류·중간에 끊김일 때만 나타납니다. **이어서 번역**은 끊긴 곳부터 이어 갑니다.

번역문은 원문 내용별로 저장되므로 스와이프마다 따로 남고, 원문을 고치면 새로 번역할 대상이 됩니다.

### 문단 대조 (Paragraph Reader)

표시 방식을 **문단 대조**로 고르면 Paragraph Reader 0.2.0처럼 원문 N과 번역 N을 문단별로 짝지어 보여 줍니다. 메시지에는 번역 내용이 나오고, 번역·다시 번역·번역 삭제는 메시지 동작 줄 버튼으로 합니다. 설정 서랍의 **문단 대조** 구역에는 모든 메시지에 적용되는 설정만 있습니다(표시 방식을 고르면 바로 나타납니다).

- **보기:** 원문·번역 교차 / 눌러서 원문(번역만 보이고, 문단마다 눌러서 원문을 펼침). 바로 저장됩니다.
- **문단 안 순서:** 교차 보기에서 문단마다 원문 → 번역 또는 번역 → 원문 중 고릅니다. 모든 채팅에 적용되고 바로 저장됩니다. "눌러서 원문"은 번역이 항상 위라 순서 설정이 없습니다.
- **도착 언어:** "내 언어"와 같은 설정입니다. 저장 버튼으로 저장합니다.
- **글자 크기:** 원문·번역을 따로 12~32px로 조절합니다. 모든 채팅에 적용되고 바로 저장됩니다. 보기 전환과 크기 변경은 다시 번역하지 않습니다.
- **번역 단위가 "문단별"이면** 문단마다 따로 요청해 정확히 짝이 맞습니다. 중간에 멈추면 "이어서 번역"으로 남은 문단만 번역합니다.
- **"메시지 통째로"이면** 1회 요청으로 번역한 뒤, 원문과 번역의 문단 수가 같으면 순서대로 짝짓고, 다르면 "원문 전체 / 번역 전체"로 보여 줍니다.
- 글자·숫자가 없는 문단(`* * *`, `---`, 태그만 있는 줄)과 코드 블록, 번역하지 않을 부분은 요청하지 않고 한 번만 표시합니다.
- 여는 태그와 닫는 태그가 다른 문단에 있는 HTML은 한 덩어리로 묶어 보여 줍니다.
- 원문과 번역문 모두 SillyTavern이 메시지를 그리는 방식(마크다운·HTML)으로 그려집니다.

### 프롬프트 프리셋

- 1.5.4의 기본 프리셋을 **모두** 넣었습니다. 기존판, v2, 의역, 영문학 번역체, 인풋용, 대사 병기를 1.5.4와 같은 순서로 보여 줍니다.
- 응답(Incoming)과 내 메시지(Outgoing) 방향마다 따로 고릅니다.
- **채팅 설정 유지**를 고르면 그 채팅의 프롬프트를 씁니다. 비워 두면 기본 번역 프롬프트(Marinara의 `You are a translator…`)를 씁니다. 입력칸에 회색 글씨로 보입니다.
- 내 프리셋을 만들고 수정·삭제할 수 있습니다. 기본 프리셋은 읽기 전용이고, 복사해서 새로 만들 수 있습니다.
- 프롬프트의 `{{targetLanguage}}`는 대상 언어로 바뀝니다.

### 단어장 · 참고 정보 (1.5.4와 같음)

- **단어장:** 한 줄에 `내 언어 용어 = 모델 언어 용어`. 양방향으로 적용되며, 원문에 나온 쪽을 보고 방향을 정합니다.
- **기타 지침:** 장르·시대·지역·배경 등. 용어 선택에만 쓰고 내용은 더하지 않도록 지시합니다.
- **대사 지침:** 응답 번역에만 `# Character Voice Instructions`로 붙습니다.
- **이전 대화 참고:** 최근 1~10개 메시지의 원문과 번역문을 참고로만 넣습니다. 기본은 응답 번역에만 넣고, 옵션을 켜면 내 메시지 번역에도 넣습니다. 숨긴 메시지는 넣지 않습니다.
- 시스템 프롬프트가 200,000자, 본문이 50,000자를 넘으면 **자르지 않고 번역을 멈추고** 알려 줍니다.

### 번역 지침 묶음

- **번역 지침 묶음**에서 단어집·추가 지침·캐릭터 말투를 이름 붙여 저장하고 방마다 하나씩 선택할 수 있습니다. **새 묶음으로 저장**은 이 방의 현재 입력 내용 3개를 복사합니다. 저장한 묶음은 목록에서 고른 뒤 아래 **저장** 버튼으로 적용하세요.
- 선택한 묶음은 **내용 보기**에서 읽기 전용으로 확인합니다. 아래 **이 방에만 추가** 입력은 그대로 남으며, 묶음 뒤에 더해집니다. 단어집에서 왼쪽 용어가 같으면 이 방의 값이 우선합니다. 묶음으로 복사한 지침이 중복되지 않게 하려면 확인 후 이 방 추가분을 비워 주세요.
- 기타 지침·대사 지침의 켜기/끄기는 방마다 정하며 묶음과 추가분 전체에 적용됩니다. 캐릭터 말투는 응답 번역에만 적용됩니다.
- **묶음 편집**은 같은 묶음을 쓰는 모든 방의 다음 번역에 반영됩니다. 이미 번역한 메시지는 **다시 번역**을 눌러야 합니다. **삭제**는 확인 후 모든 방과 기본값의 묶음 선택을 **없음**으로 바꾸며, 각 방에 입력한 추가분은 보존합니다. 기존 설정과 번역 기록도 그대로 유지됩니다.

### 번역하지 않을 부분

- **HTML:** 태그와 속성(`<div class="…">` 등), `<style>`·`<script>` 내용, 주석은 그대로 두고 태그 사이 글자만 번역합니다.
- **코드 블록:** ` ``` ` 안은 번역하지 않습니다.
- **`{{매크로}}`:** 항상 그대로 둡니다.
- **제외할 HTML 태그:** `choices, status` 처럼 태그 이름을 쉼표·공백으로 적으면, 그 태그의 요소 전체(여는 태그부터 닫는 태그까지, 안쪽 내용 포함)를 번역에 보내지 않고 그대로 되돌립니다. 같은 이름이 중첩돼도 짝을 맞춰 찾고, 닫히지 않은 요소는 글 끝까지 보호합니다. 코드 블록과 주석 안의 태그는 무시하고, `<br>` 같은 빈 태그와 `<x/>` 형태는 범위로 잡지 않습니다. `strong`·`em` 은 안쪽 글자를 계속 번역합니다(태그만 유지). **추천 태그 넣기** 버튼이 `choices, options, status, stats` 를 더합니다. 기본값은 비어 있습니다.
- **`<style>`·`<script>`:** 위 HTML 설정을 꺼도 항상 그대로 둡니다.
- **제외 규칙:** 한 줄에 하나씩 적습니다.

  ```text
  <status>                  ← <status ...>...</status> 요소 전체
  /HP: \d+\/\d+/            ← 정규식과 일치하는 부분
  [상태창] ... [/상태창]     ← 시작부터 끝까지 (" ... " 로 구분)
  ```

보호한 부분은 번역 전에 `⟦1⟧` 같은 표시로 바뀌어 모델에 원문이 가지 않고, 번역 후 원래대로 돌아옵니다. 원문에 `⟦1⟧` 이 이미 있어도 우리 표시와 섞이지 않게 먼저 따로 보관합니다(그래서 번호 외에 별도의 무작위 값은 쓰지 않습니다). 모델이 표시를 빠뜨리거나 늘리면 한 번 다시 번역하고, 그래도 어긋나면 **표시 사이의 글을 하나씩 따로 번역해 표시를 우리가 다시 끼워 넣습니다**(요청이 늘어나므로 조각이 40개를 넘으면 하지 않습니다). 그것도 안 되면 HTML이 깨지지 않도록 그 부분을 저장하지 않고 오류로 알립니다.

### 번역문의 HTML

번역문은 SillyTavern이 메시지를 그리는 방식(마크다운, HTML)으로 그대로 그려집니다. 원문의 카드·상태창 HTML이 번역문에서도 똑같이 보입니다. 응답의 저장된 원문은 바뀌지 않고, AI에게 가는 대화 기록에도 원문이 들어갑니다. 단, 내 메시지를 보내기 전에 번역하는 경우에는 번역문이 메시지 내용이 됩니다.

### 긴 지문

설정한 글자 수(기본 7,000자) 이상이면 문단 단위로 약 3,200자씩 나눠 차례로 번역합니다. 조각이 끝날 때마다 저장되므로 중간에 실패해도 **이어서 번역**으로 남은 조각부터 계속합니다.

### 다른 확장과 함께 쓰기 (LoreVeil · 오토픽 · Tavern Helper)

설정 창의 **다른 확장과 함께 쓰기**에서 켜고 끕니다. 모두 기본으로 켜져 있고 바로 저장됩니다. 끄면 예전과 똑같이 동작합니다.

- **LoreVeil 태그 보호 (내 메시지 번역)** — 내 메시지를 보내기 전에 번역할 때, LoreVeil 설정에 적은 태그(`<st-loreveil>`처럼 여는 태그와 닫는 태그, 기본 태그 포함)와 `!--이름_START--!` / `!--이름_END--!` 표시를 번역하지 않고 그대로 되돌립니다. 사이의 글은 번역하고, 번역 뒤에도 이 표시들의 앞뒤 순서가 같아야 합니다. 순서가 바뀌면 다시 시도하고, 그래도 안 되면 조각별 번역으로 넘어갑니다. 제 한계는 이렇습니다.
  - `<div 태그>` 같은 **속성 방식**은 여는 태그만 항상 지킵니다. 닫는 `</div>`까지 지키려면 "번역하지 않을 부분"의 **HTML 보호**가 켜져 있어야 합니다.
  - LoreVeil 설정은 `extensionSettings.loreVeil`에서 읽습니다. LoreVeil이 없으면 기본 태그(`st-loreveil`)만 지킵니다.
- **오토픽 블록 보호** — 응답 속 `<autopic>…</autopic>` 블록은 모델에 보내지 않고 번역하지 않으며, 그대로 되돌립니다. 원문과 번역을 함께 보여 주는 표시 방식(원문 아래/위, 접기)에서는 이 블록과 코드 블록(```)·제외 태그 요소가 **한 번만** 나옵니다(원문이 붙은 쪽에 남김). 메시지 본문과 오토픽의 이미지 정보(`extra.autopic_*`, `extra.media`)는 건드리지 않고, 메시지 받음 같은 SillyTavern 이벤트도 보내지 않습니다.
  - **확인 필요:** 오토픽의 `translationCompatibility: "slots"` 모드가 본문에 표시를 써 넣는지, 나중에 본문을 다시 고치는지는 확인하지 못했습니다. 본문이 바뀌면 이 확장은 그 번역을 오래된 것으로 보고 다시 번역하게 합니다.
- **JS 러너(Tavern Helper) 다시 그리기** — 번역 표시를 바꾸면 메시지 칸이 다시 그려져 Tavern Helper의 iframe이 사라집니다. 그래서 칸을 바꾼 직후, Tavern Helper가 듣고 있을 때만 `TH_REQUEST_RENDER_MESSAGE`(메시지 번호)를 한 번 보냅니다. 코드 블록은 번역하지 않으므로 같은 코드가 한 번만 그려집니다.
  - 이 이벤트 이름은 Tavern Helper **내부** 이름이라 버전이 바뀌면 달라질 수 있습니다. 달라지면 다시 그리기만 멈추고 번역은 그대로 동작합니다.
- **디버그 로그** — 켜면 다시 그릴 때마다 브라우저 콘솔에 `TH rerender mesid=번호`를 남깁니다.

## LV-Translator(Lumiverse판)와 다른 점

- **연결:** Lumiverse 연결 대신 SillyTavern 연결 프로필(Connection Manager) 또는 지금 쓰는 API를 씁니다. 연결 프로필이 없으면 지금 쓰는 API로 번역합니다.
- **설정 위치:** Lumiverse의 서랍 "번역" 탭과 입력창 Extras 메뉴 대신, 확장 패널의 **양방향 번역** 서랍과 마술봉 메뉴의 **번역 설정**입니다.
- **권한:** Lumiverse의 권한 허용(`generation`, `chat_mutation`) 절차는 없습니다.
- **번역 실행 위치:** 서버 쪽 동작이 없습니다. 모든 번역은 브라우저에서 실행되며, 탭을 닫으면 진행 중인 번역도 멈춥니다. 응답 자동 번역도 브라우저가 열려 있을 때만 동작합니다.
- **끊김 감지:** 지금 쓰는 API로 번역할 때는 모델이 멈춘 이유를 알 수 없어 자동 이어서 번역을 쓸 수 없습니다. 연결 프로필을 쓰면 가능합니다.
- **최대 출력 토큰:** 번역 최대 출력 토큰 설정이 새로 생겼습니다.
- **내 메시지 번역:** Lumiverse의 메시지 생성 요청 가로채기 대신 SillyTavern의 메시지 전송 이벤트를 씁니다. 메시지가 보내지는 시점에 AI가 받기 전에 번역합니다. 그룹 채팅에서도 번역합니다.
- **입력창 번역 버튼:** Lumiverse 입력창 대신 SillyTavern의 보내기 폼 옆에 붙습니다.
- **메시지 버튼:** 말풍선 전용 장착 지점 대신 SillyTavern의 메시지 동작 줄에 번역(지구본)·번역 삭제(지우개) 아이콘을 붙입니다.
- **표시 방식:** 화면에 보이는 결과(표시 방식에 따라 조립한 번역문)를 SillyTavern의 메시지 `display_text`에 저장합니다. 그래서 SillyTavern이 메시지를 처음 그릴 때부터 번역문이 나와 원문이 깜박이지 않고, 채팅 파일에 그대로 남으며, 이 확장을 꺼도 번역문이 보입니다. 번역 기록(`st_translator`)은 스와이프별로 함께 보관합니다.
- **내장 Chat Translation:** 내장 기능도 같은 `display_text` 자리를 씁니다. 함께 켜 두면 이중 번역이 되므로 끄세요. 이 확장은 자기가 쓴 `display_text`만 소유 표시(해시)로 기억해서 바꾸거나 지우고, 번역문이 없을 때는 내장 기능이나 다른 것이 쓴 `display_text`를 건드리지 않습니다. 내장 번역 버튼으로 "원문 보기"를 하면 이 확장의 번역문도 사라지고, 다음에 이 확장이 번역문을 쓸 때까지 원문이 유지됩니다.
- **번역 숨기기:** 원본처럼 메시지 전체에 적용됩니다(모든 스와이프).
- **연결:** 채팅마다 저장하지 않고 모든 채팅에 공통입니다.
- **지금 쓰는 API로 번역할 때 온도:** 연결 프로필로 번역할 때는 온도 0.3으로 요청하지만, 연결 프로필이 없어 SillyTavern의 지금 쓰는 API(`generateRaw`)로 번역할 때는 온도를 지정할 수 없어 그 API의 샘플러 설정을 따릅니다. 번역이 들쭉날쭉하면 연결 프로필을 만들어 쓰세요.

## Marinara · 1.5.4와 다른 점

- 번역 제공자는 AI 연결만 지원합니다(Google·DeepL·DeepLX 없음).
- 1.5.4의 "후처리 후 번역" 옵션은 없습니다. 항상 생성이 끝나고 저장된 최종 응답을 번역합니다.
- 1.5.4에서 "채팅 설정 유지" + 빈 채팅 프롬프트 + 대사 지침을 켜면 번역 지시문 없이 대사 지침만 보내지는데, 여기서는 기본 번역 프롬프트를 앞에 유지합니다. 나머지 요청 형식은 1.5.4와 같습니다(테스트로 확인).

- **자동 테스트(`bun test`) 349개**: LV-Translator에서 가져온 순수 로직 테스트 194개(프리셋 SHA-256 지문, 1.5.4 요청 기록과 글자 단위 일치 포함)와, SillyTavern 연결·저장·스와이프·표시·호환 테스트. 타입 검사와 빌드도 통과.
- **실제 SillyTavern 1.19.0(release) + 가짜 OpenAI 호환 서버 + 헤드리스 브라우저**에서 확인한 것:
  - 설치·설정 서랍·마법봉 메뉴, 수동·자동 번역(연결 프로필, temperature 0.3), 상태창 HTML 보존
  - 표시 방식 6종과 문단 대조(글자 크기 조절), 새로고침 후 유지, **확장을 꺼도 번역 유지**
  - 스와이프별 번역, 새 스와이프·이어 쓰기(스트리밍 켬/끔 모두), 수정 후 오래된 번역 제거, 번역 삭제, 번역 중 스와이프 삭제
  - 끊긴 번역 자동·수동 이어서 번역, 취소, 내 메시지 번역, 입력창 번역 버튼, 기본 번역이 쓴 번역문 보존, 휴대폰 390px 화면
  - **LoreVeil 1.0.0**: 내 메시지 번역 뒤에도 태그·마커가 글자 그대로 남고, 가린 구간의 키워드가 로어북을 발동하지 않음. 모델이 태그 순서를 바꾸면 다시 번역해 바로잡음
  - **Tavern Helper 4.12.0**: 번역·표시 방식 전환·숨기기·삭제·수정 취소 뒤에도 iframe이 정확히 1개, 다시 그리기 요청은 변경마다 1번
  - **오토픽**: 코드를 열지 않고 `<autopic>` 블록이 든 답변 데이터로만 시험. 블록이 번역 요청에 들어가지 않고, 표시 방식마다 한 번만 보이며, `mes`·`extra.autopic_*`·`extra.media`가 바뀌지 않음
- **확인하지 못한 것:** 실제 AI 모델의 번역 품질, 실제 오토픽 확장과 함께 쓸 때(특히 `slots` 모드), 사용자 서버(도커)·테일스케일 경로, 텍스트 완성(Text Completion) 연결 프로필, 그룹 채팅
- API 키가 틀렸을 때 제공자의 원래 오류 문구 대신 "Unauthorized"가 보입니다. SillyTavern 서버가 상태 문구로 바꿔 넘기기 때문입니다.

## 개발

```bash
bun install
bun test
bun run typecheck
bun run build     # dist/ 생성 — 변경 후 dist도 함께 커밋
```

SillyTavern은 `dist/index.js`를 그대로 읽으므로 `dist/`를 커밋합니다. 확장의 진입점(`manifest.json`의 `js`)과 스타일(`style.css`)은 저장소 루트에 있습니다.

- `src/presets/` — 1.5.4 프리셋 원문(수정 금지, 지문 테스트로 보호)
- `src/translate/prompt.ts` — 번역 요청 조립(1.5.4 이식)
- `src/translate/protect.ts` — HTML·제외 규칙 보호와 복원
- `src/translate/chunk.ts` — 긴 지문 나누기, 이어 붙이기
- `src/translate/engine.ts` — 번역 진행(부분별 번역, 이어서 번역, 재시도)
- `src/translate/paragraphs.ts` — 문단 나누기, 글자 없는 문단, HTML 묶기(Paragraph Reader 0.2.0 이식)
- `src/display/paragraph-view.ts` — 문단 대조 화면
- `src/display/render.ts` — 표시 방식별 메시지 조립
- `src/st/` — SillyTavern 호스트 연결(설정 저장, 번역 기록, 자동 번역, 표시, 메시지 버튼, 내 메시지 번역, 입력창 버튼, 설정 서랍)
- `src/message-ui.ts` — 버튼 상태, 스와이프별 번역 삭제 같은 순수 로직
- `tests/fixtures/upstream-requests.json` — 1.5.4가 실제로 만든 번역 요청(비교 기준)

타사 코드 고지는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.
